# 🍔 Food Delivery Logistics Optimization | Python & Power BI


##  Project Title
**Food Delivery Logistic Optimization **


## Project Overview

This project focuses on analyzing food delivery operations to identify the factors affecting delivery time and operational performance.

Using Python for data preparation and Power BI for data visualization, the project explores how factors such as traffic density, weather conditions, vehicle condition, multiple deliveries, and festivals influence delivery time.

The objective is to transform raw delivery data into meaningful insights that can support better operational decisions and improve delivery efficiency.

The project applies **Business Intelligence concepts**, including ETL, data modeling, KPI design, and dashboard development, to support **data-driven decision-making**.

---

## Methodology

The project followed a data analytics workflow:

1. **Data Understanding:** Explored the dataset and identified the main variables affecting delivery time.
2. **Data Cleaning & Preparation:** Used Python to inspect, clean, and prepare the dataset for analysis.
3. **Data Transformation:** Organized the data and prepared it for analytical use.
4. **Data Modeling:** Designed a star schema with a Delivery Fact Table and supporting Dimension Tables.
5. **Dashboard Development:** Built an interactive Power BI dashboard to analyze delivery performance.
6. **Business Analysis:** Examined the impact of traffic, weather, vehicle conditions, multiple deliveries, and festivals on delivery time.

## Power BI Dashboard

The interactive dashboard provides insights into food delivery operations through key performance indicators and visual analysis.

### Key Performance Indicators (KPIs)
- **Average Delivery Time:** Measures the average time required to complete deliveries.
- **On-Time Delivery:** Evaluates delivery punctuality.
- **Festival Rate:** Analyzes the proportion of orders associated with festivals.

### Analysis Dimensions
- Road traffic density
- Weather conditions
- Vehicle condition
- Multiple deliveries
- Festival impact
- Delivery trends over time

The dashboard enables users to explore delivery patterns and identify operational factors that may affect delivery performance.
